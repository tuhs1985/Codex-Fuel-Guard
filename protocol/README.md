# Installed protocol artifacts

`verified/` contains selected JSON schemas generated by the installed OpenAI Codex 0.153.4 executable, plus their capture manifest. These artifacts originate from [OpenAI Codex](https://github.com/openai/codex), licensed under [Apache-2.0](https://github.com/openai/codex/blob/main/LICENSE).

Run `scripts/capture-protocol.ps1` after a Codex upgrade and review differences before claiming compatibility. Full generated output is kept locally in ignored `protocol/generated/`.
